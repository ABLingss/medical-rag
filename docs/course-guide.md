# 课堂汇报与实践指南

推荐项目标题：**知医 医学名词与机制学习卡片生成器**。

副标题：基于可溯源知识库与提示词约束的医学生复习辅助系统。

本项目用自建网页加DeepSeek Flash实现可展示的智能体，不需要训练模型，也不要求使用Coze。课堂要求的实际调研、风险实证、不同工具运行和小组反思仍由小组完成。

## 七项待验证痛点

1. 名词数量多，复习时整理卡片耗时。
2. 机制过程抽象，学生难以建立因果顺序。
3. 相近术语容易混淆，定义边界不清。
4. 缺少与当前学习内容匹配的自测题。
5. 通用AI解释可能超出本校教材范围。
6. AI可能编造出处、页码或数值。
7. 重复生成常出现同质化表达。

以上是项目设计假设，不是已经完成的调研结果。建议访谈3至5名同学，记录课程、问题实例、频次与匿名原话，再决定哪些痛点保留。

## 建议实验编号

- P01至P03：心力衰竭、GFR、炎症因子分别做粗放/精细对照。
- H01至H03：不存在的滤过定律、教材第888页、IL-999浓度。核查是否拒绝假前提，是否编造引用。
- L01至L03：正常射血分数能否排除心衰、GFR是否等同尿量、所有细胞因子是否只有促炎作用。先补充支持辨析的教材片段，否则合理结果应说明资料不足。
- S01：同一个基础机制任务，粗放与精细各连续3次。记录三字片段Jaccard相似度，人工核查是否仅换说法、是否出现知识点遗漏。
- T01至T03：两个真实工具分别运行完全相同的精细提示与材料。

## 评价口径

| 维度 | 建议记录方式 |
| --- | --- |
| 结构完整性 | 解释、机制、辨析、卡片、自测、风险、引用7项，逐项标记有无 |
| 事实幻觉 | 逐条结论核查，列出无证据或与教材矛盾的原句与证据 |
| 逻辑严谨度 | 检查因果、条件与概念偷换，说明错误类型 |
| 不确定信息 | 资料不足时是否明确提示，是否编造精确值 |
| 同质化 | 人工比较知识点与表达，文本相似度仅作辅助 |

各项可用0至2分：0为不满足、1为部分满足、2为满足。失败调用单列，不按“没有错误”计分。样本少时只做描述性结果，不宣称统计显著或“消除幻觉”。人工评分建议两人独立核对，再讨论分歧。

## 可复现记录要求

每次保留实验ID、时间、模型、提示词原文、同一资料快照、生成参数、原始输出、API错误、人工观察和结论。网页JSON导出覆盖运行字段，教材版次、人员与评分另行补充。模型服务随时间改变，固定提示与参数也不能保证逐字复现。

## 三分钟演示脚本

1. 打开网页，展示DeepSeek Flash连接状态与能力边界。
2. 输入心力衰竭，生成解释与机制，展开来源片段。
3. 翻面一张卡片，回答一道自测题，收藏并导出。
4. 打开知识库，展示一份自行导入的教材章节与页码。
5. 展示一条已完成的提示对照，指出不同约束与真实结果。
6. 展示一个资料不足的例子，说明拒绝编造的设计和局限。

网络不稳定时可切换离线教学示例，但必须口头说明是预制内容，不作为真实AI对照实验。
