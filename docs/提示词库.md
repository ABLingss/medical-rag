# 医学学习提示词库

版本：v1.0。阶段2独立文档，阶段4附录A引用本库。正式实验以导出JSON中messages为准。

## M1 解释与机制

输入：用户问题与实际检索资料片段。

提示词原文：

用本科医学生能理解的中文解释概念；把机制拆成有顺序的因果步骤，不把相关性写成因果性。每项结论应由资料支持；资料不足就说明缺失。

输出：对应学习模块，引用只能使用实际片段ID。

## M2 概念辨析

输入：用户问题与实际检索资料片段。

提示词原文：

选择资料中存在的易混概念，逐项说明定义与区别。不从单一指标直接推导诊断，不引入资料之外的阈值。

输出：对应学习模块，引用只能使用实际片段ID。

## M3 记忆卡片

输入：用户问题与实际检索资料片段。

提示词原文：

生成 3 张问答卡片，每张只测试一个知识点，并标注 sourceIds。口诀标明为记忆辅助，不替代定义。

输出：对应学习模块，引用只能使用实际片段ID。

## M4 自测与反馈

输入：用户问题与实际检索资料片段。

提示词原文：

生成 3 道四选一题，只有一个正确答案，answer 是 0 到 3 的整数。给出资料支持的答案解析与 sourceIds，避免争议题。

输出：对应学习模块，引用只能使用实际片段ID。

## M5 风险与溯源

输入：用户问题与实际检索资料片段。

提示词原文：

核对资料是否足以支持输出，明确版本差异、证据不足与引用边界。不得编造文献、页码或数值。不回答个人诊断或用药方案。

输出：对应学习模块，引用只能使用实际片段ID。

## 相同用户消息结构

两组均发送task、materials与outputSchema，统一格式与资料是实验控制变量。精细组增加证据、边界、模块约束，粗放组没有这些系统约束。

```json
{
  "title": "医学术语",
  "summary": "通俗解释",
  "mechanism": [
    "有顺序的机制步骤"
  ],
  "comparison": [
    {
      "concept": "易混概念",
      "distinction": "区别"
    }
  ],
  "mnemonic": "记忆口诀（仅辅助）",
  "cards": [
    {
      "front": "卡片正面",
      "back": "卡片背面",
      "sourceIds": [
        "资料片段ID"
      ]
    }
  ],
  "quiz": [
    {
      "question": "自测问题",
      "options": [
        "A",
        "B",
        "C",
        "D"
      ],
      "answer": 0,
      "explanation": "解析",
      "sourceIds": [
        "资料片段ID"
      ]
    }
  ],
  "risks": [
    "不确定信息与能力边界"
  ],
  "sourceIds": [
    "实际使用的资料片段ID"
  ]
}
```
