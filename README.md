# 知医 Medical RAG

面向医学生的医学术语与机制学习工作台。输入一个术语，获得通俗解释、机制步骤、概念辨析、翻面记忆卡片、自测题和来源片段。配有课程实践所需的提示词库与实验记录。

## 本地启动

需要 Node.js 22.13 或更高版本。

```sh
npm ci
cp .env.example .env
npm start
```

打开 http://localhost:3000 。不填 AI 密钥也能使用内置主题的预制教学示例。该示例不是实时 AI 生成。当前机器已配置的 `.env` 不要覆盖。

真实生成：在 `.env` 中填写 `AI_API_KEY`。默认调用 DeepSeek 的 `deepseek-flash`，非思考模式。密钥只在后端使用，`.env`、上传资料、运行日志和本地验证记录都不会进入 Git。前端的“连接与设置”只接收访问口令，不能接收模型密钥。

本机浏览器同源访问、且服务绑定回环地址时，自动获取会话口令。其他设备需要在设置中输入 `ADMIN_TOKEN`；未配置时启动终端会显示随机口令。口令只留在当前页面内存，刷新后需重新输入。本地配置已有固定口令时可在 `.env` 中查看，请勿分享模型密钥。

## 功能

- 学习：AI生成或预制教学示例，清楚标记模式，不将失败伪装成成功。
- 卡片与自测：点击翻面，四选一反馈和得分，收藏到当前浏览器，导出Markdown笔记。
- 知识库：导入PDF、TXT和Markdown，保留PDF物理页码，展示检索原文，删除自建资料。
- 实验：粗放/精细提示对照、粗放与精细各3次重复、多工具比较，保存真实提示、参数、模型、耗时、用量和资料快照，填写人工评价并导出JSON。
- 提示词：解释机制、辨析、卡片、自测、风险溯源五个模块。

收藏和实验记录保存在当前浏览器，不跨设备同步。请及时导出。上传资料保存在 `data/knowledge.json`，可备份此文件。持久化写入采用临时文件与原子替换。

## 知识库如何准备

内置4份原创中文教学摘要，覆盖心力衰竭、GFR/eGFR、炎症细胞因子和估算值边界。基础资料链接来自 NIH/NHLBI、NIDDK 与 NCBI。摘要不是教材原文，也不覆盖完整课程。详细来源、适用范围和使用限制见 [知识库说明](docs/knowledge-sources.md)。

最方便的扩充方式：在网页知识库上传本校教材的目标章节PDF，资料名称填清教材名、版次和章节。仅上传你有权使用的学习材料，勿上传患者记录。单文件最大10MB、500页、100万字符。扫描版需先OCR，文本文件需UTF-8。总容量最多100份自建资料、500万字符。

分段为800字符、重叠150字符，不跨PDF页，保留标题和物理页码。检索为中文双字片段与英文词、标题加权、常用别名扩展的本地词法检索，召回最多5段；分数只是排序权重，不是置信度。系统不依赖向量数据库、嵌入服务或Coze，也没有训练新模型。长教材和语义改写场景可能漏检，扩展建议见资料说明。

网页来源链接仅作引用，不自动抓取网页。导入网页内容请保存为TXT/Markdown后上传，同时填原始链接。

## 真实实验

对照实验中，两组使用相同问题、检索上下文、输出JSON结构与生成参数，只改变系统提示。粗放组的JSON要求是为保持相同输出界面，不是完全无格式约束的裸提示，报告中应说明这一控制。未检索到资料时，普通学习停止生成；专项风险实验仍允许真实调用，以观察模型是否会编造。

在 `.env` 填写 `AI_COMPARE_API_KEY`、`AI_COMPARE_BASE_URL`、`AI_COMPARE_MODEL` 接入第二个OpenAI兼容工具。没有第二个工具时，网页明确提示未配置，不以同一个模型冒充横向对比。相同模型不同平台不能直接等同于不同基础模型。

“引用存在”与“符合结构”不是医学真实性证明。失败的结构校验也不直接等同于幻觉，应单独记录。人工评价时逐项对照教材。实验方案与填表方法见 [课程实践指南](docs/course-guide.md)。

## 服务器与容器

以后需要让其他设备访问，在 `.env` 设置 `HOST=0.0.0.0`，`PORT`默认3000。本地自动获取口令随之禁用。公网IP、域名、端口映射由部署者处理。后端必须一同运行，不能仅把 `public/` 当作独立静态站点发布。

```sh
docker compose up -d --build
```

先准备 `.env`。容器挂载 `./data`，重建不丢知识库。Docker构建排除 `.env`。真实AI调用和资料修改要求口令，并限制同一地址每分钟10个请求、全局2个并发AI任务和1个资料导入任务。这是课堂/小组应用，不含多用户账户隔离。公网使用建议在反向代理配置HTTPS、请求大小和流量限制，口令控制不能代替完整账户系统。


## 能力边界

本项目用于课程复习，不支持个人诊断、处方、药物剂量或替代教材。关键词拦截和提示词均不能完全消除越界或幻觉。上传资料可能包含错误或恶意指令，提示约束只是缓解措施。检索片段会随生成请求发送给所配置的AI服务；离线示例和本地检索不发送给AI服务。
